La revisión humana final corresponde al equipo. Para registrar la aceptación, anoten el commit revisado, quién comprobó cada flujo, el resultado y los pendientes. El [manual](manual-edicion.md) incluye el guion de demostración. El [diccionario](modelo-datos.md) identifica las restricciones que se verifican en SQL Server y las reglas que aplica la API.

En la revisión de esta entrega pasaron 18 pruebas de frontend, 113 comprobaciones de C# y 3 comprobaciones del manifiesto de respaldo. En una base nueva de SQL Server Express se verificó desde el navegador el cambio de portada, la edición de producto y servicio, las fechas en la vista previa y la aparición y retiro automáticos de una promoción en la misma pestaña. También se comprobó el horario en contacto y pie de página y el archivo de una foto de galería.
